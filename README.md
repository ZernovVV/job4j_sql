# job4j_sql

## Учебный проект по изучению SQL и проектированию реляционных баз данных на PostgreSQL

Изучаются и прорабатываются темы: 
основы реляционных баз данных и устройство PostgreSQL;
типы данных PostgreSQL и принципы их выбора;
создание таблиц, изменение их структуры и описание связей между ними;
первичные и внешние ключи, а также ограничения NOT NULL, UNIQUE, CHECK;
вставка, обновление, удаление и выборка данных;
фильтрация, сортировка, группировка и агрегатные функции;
соединения таблиц и подзапросы;
транзакции и базовые вопросы целостности данных;
индексы и их влияние на производительность запросов;
проектирование схемы базы данных и решение практических задач на SQL.
